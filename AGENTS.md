# Agentic Development

- Before making changes, read and follow the coding standards in [docs/coding-standards.md](docs/coding-standards.md) and any applicable guidance in the `docs/` directory.
- After every major change or completed set of changes, provide a suggested commit message.
- Commits use only the user's own git author and committer identity. Do not add LLM or agent attribution anywhere in commits, such as `Co-Authored-By` trailers, tool or model names, or "Generated with" lines.
