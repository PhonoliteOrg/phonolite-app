# v0.4.0

## Added

- Gapless playback for streamed and downloaded tracks, with upcoming tracks
  prepared before the current track ends. Compatible tracks share one audio
  output, including repeat, shuffle, repeated track IDs, and very short tracks.
  Queue position, playback bookmarks, and listening attribution advance when
  the next track becomes audible.
- A device-specific Seamless mixed-format playback setting. When enabled,
  tracks with different sample rates or channel layouts are converted to a
  shared output format. It is disabled by default to preserve each track's
  native format; changing formats can briefly interrupt playback in that mode.
- Auto streaming quality that adjusts between Low, Medium, High, and Original
  during playback. Original is prepared alongside compressed audio and selected
  when delivery and buffered audio are sufficient, with a compressed fallback
  when they are not. Recent successful Original playback can warm the next
  track without holding up startup indefinitely.
- Original and downloaded playback support for AAC in ADTS and MP4, ALAC,
  Ogg Vorbis, Ogg Opus, WAV, and AIFF, alongside MP3 and FLAC.
- Download quality settings for Space saver (64 kbps Opus), Standard (96 kbps),
  High (128 kbps, recommended), Very high (192 kbps), and Original. The preference
  is saved on the device, defaults to Original, and applies to future downloads;
  existing downloads retain their quality. The chooser includes storage estimates.
- Native macOS support with CoreAudio playback and output-device selection,
  menu-bar and window integration, launch at login, system Now Playing artwork,
  and media commands. Custom storage folders use a native chooser and persistent
  sandbox bookmarks, with access restored before storage opens at startup.
- Linux desktop support with native decoding, QUIC streaming, secure storage,
  file selection, tray and window integration, autostart, and 16/32-bit PCM
  playback through PulseAudio or PipeWire's PulseAudio compatibility service.
- Linux package builders for `.deb`, `.rpm`, and `.pkg.tar.zst`, plus signed
  GitHub update discovery, package verification, a separate update coordinator,
  and a polkit-authorized installer. Production rollout remains gated on signing
  setup and validation of each target and desktop update flow.
- Best-effort playback presence on supported servers, with heartbeats while
  playing and stop reports on pause or shutdown. Presence is separate from
  listening-history collection and does not block playback when reporting fails.

## Changed

- Auto replaces Original as the initial streaming mode. The quality chooser
  retains the fixed Original, High (160 kbps), Medium (96 kbps), and Low
  (48 kbps) options. Auto shows the currently audible rendition as `OG`, `HQ`,
  `MQ`, or `LQ`, and playback controls show buffered audio ahead in seconds.
- Original streaming uses authenticated QUIC source reads instead of the
  playback HTTPS byte-range path. Reconnects verify the trusted server and the
  same source version and length before joining retained audio.
- Streaming recovery retains accepted audio across transient failures and
  network changes, resumes at the missing byte or audio frame, and bounds
  reconnect attempts. Android and Apple hosts report route changes separately
  from seeks and cancellation. Longer interruptions use delayed retries while
  preserving the current track, position, and playback intent.
- Adaptive buffering remembers weak connections, retains useful audio while
  waiting for continuation headers, and limits read-ahead while paused.
  Compressed-quality changes can retain the existing output and presentation
  timeline.
- Download requests capture their selected quality before server preparation
  and preserve it across pause, resume, and app restarts. Prepared renditions
  are checked against the requested profile, and compressed downloads retain
  their own file identity and exact playback timing.
- The download manager shows queued collection tracks before individual
  transfers exist, including tracks outside the active transfer window. Album
  download actions reflect preparation, validation, pause, removal, and retry
  states as job snapshots change.
- Artist catalogue refreshes retain the loaded browsing window until a complete,
  consistent replacement is ready. Failed refreshes keep the previous content
  visible. Local search reuses revision-scoped results, and artwork-cache writes
  avoid repeated full-directory scans while retaining bounded storage.
- Playback metadata and artwork warm independently of audio startup. Cover
  failures no longer prevent a track from starting, and upcoming covers are
  decoded ahead of their display with bounded concurrency and cache retention.
- Desktop controls use consistent pointer cursors and hover behavior, and the
  compact player retains stable artwork bounds while metadata or images load.

## Fixed

- Corrected seek and gapless handoff races so obsolete reads, cancellations,
  and prepared successors cannot stop or seek a replacement track. Pausing,
  scrubbing, changing tracks, and stopping release the appropriate prepared
  audio while retaining the latest user intent.
- Corrected codec delay, padding, and exact playable-frame handling for gapless
  decoding, including AAC/ALAC MP4 edits and Ogg Opus timing and seeking.
  Very short or empty sources no longer create phantom transitions or wait
  indefinitely for audio that cannot be rendered.
- Repeated FLAC seeks after reading ahead to the end discard stale frame
  fragments and retain the correct samples from the requested position.
- Prevented Play from bypassing an underrun refill gate. Stalled output now
  retires playback for recovery, and temporary transport failures can recover
  without discarding already buffered audio or resetting the output device.
- Auto keeps compressed playback available when Original preparation fails,
  its source is unsupported, or the output cannot initialize PCM32. Quality
  reporting follows the audio being rendered rather than prefetched data.
- Improved iOS recovery from audio interruptions, hardware-route changes, and
  media-services resets. Explicit Play or track selection can reactivate an
  interrupted session when no interruption-ended event arrives; newer Pause
  requests remain authoritative, and a services reset requires explicit Play.
- CarPlay preserves the selected or restored library source while its root
  interface is installed or replaced, and ignores stale scene completions.
  Saved iOS credentials migrate to first-unlock Keychain accessibility so
  CarPlay can restore a session while the screen is locked after the first
  device unlock.
- Corrected missing playback artwork when track metadata needs hydration,
  including shuffle playback, and prevented late cover work from replacing
  newer metadata.
- Corrected Windows accessibility-tree errors from slider popups during startup,
  route transitions, retained tabs, and enabled-state changes. Slider overlays
  remain inside their route's visibility scope.
- Download cancellation during server preparation cannot revive canceled work.
  Pausing an in-flight request retains its remote job for resume, and overlapping
  preparation cannot replace another active rendition. Existing Original files,
  likes, and playlist membership survive the download schema upgrade.
- Server-address input rejects edits containing invalid URI characters without
  silently changing a pasted hostname, and the port field accepts digits only.

## Compatibility

- Original streaming requires a server implementing the QUIC source protocol.
  Auto's Original upgrade requires source metadata from the server; compressed
  download profiles and playback presence also depend on server support.
  Unsupported compressed download profiles report an error instead of silently
  downloading Original.
- Original preserves source bytes in transit; lossy sources remain lossy.
  The decoder supports mono and stereo sources with up to 32-bit precision.
  Auto and Seamless mixed-format playback can convert sample rates and channel
  layouts, and the operating-system mixer or hardware can also convert output.
- macOS requires version 13 or later. macOS distribution uses the shared
  Phonolite App Store listing, and the Mac App Store manages updates. See the
  [macOS build and signing notes](../README.md#macos).
- Linux currently uses the system default audio output. Native device
  enumeration and MPRIS media integration remain unfinished. Candidate package
  targets are Ubuntu 26.04, Fedora 44, RHEL 10.0, and Arch rolling on x86_64;
  all remain unvalidated for production updates. See the
  [Linux release and validation notes](../docs/linux_distribution_update_plan.md).
- QUIC path migration is disabled by default and requires both the
  `PHONOLITE_QUIC_MIGRATION=true` build setting and the server's
  `quic_allow_client_migration` option. Normal network recovery uses buffered
  reconnects. Migration changes the route to the same server rather than
  selecting another server endpoint.

## Maintenance

- Updated the app version from `0.3.0+1` to `0.4.0+1`, raised the toolchain
  requirement to Flutter 3.47 and Dart 3.13, and refreshed dependencies.
- Added shared native audio timeline and progress support, native build hooks
  for the macOS audio and QUIC frameworks, Swift Package Manager integration,
  and local secure-storage forks for macOS and Linux.
- Standardized the Android application ID as
  `com.phonoliteorg.phonolite_app` and the iOS/macOS bundle ID as
  `com.phonoliteorg.phonolite`.
- Added vendored MP4 and Ogg demuxer patches with provenance notes, and updated
  QUIC transport handling to reclaim canceled stream slots and flow-control
  credit during repeated seeks.
- Expanded regression coverage for adaptive quality, Original fallback,
  gapless transitions, seek cancellation, network recovery, download profiles
  and pending tracks, artwork, catalogue refreshes, accessibility, CarPlay,
  macOS storage permissions, and Linux audio, packaging, and updates. Added
  native accessibility replay and platform contract checks.
