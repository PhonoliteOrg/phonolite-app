# v0.3.0

## Added

- Original audio quality for streaming MP3 and FLAC files at their source
  bitrate over authenticated HTTPS byte ranges, bypassing Opus transcoding.
  Downloaded playback shares the same decoder. Source sample rate and
  16/24/32-bit integer precision are preserved through the app's PCM32 path.
- Named custom shuffle presets with create, edit, apply, select, and delete
  actions, plus an option to import existing server filters. Presets synchronize
  across the account on supported servers. Applying a preset changes playback
  on the current device.
- Conflict handling for shuffle preset edits: keep an open draft when another
  device changes or deletes its preset, with options to reload or save a copy.
- Playback restoration across app restarts, including the current track, queue,
  source, shuffle context, and device seek position. Restoration prepares the
  player paused, and an explicit playback action takes precedence.
- Account playback bookmarks and durable shuffle-deck restoration on supported
  servers, with a last-track fallback for older servers. Device queue order and
  seek position remain local; other devices' updates do not take over active
  playback.
- Local playlists can contain server tracks before their audio is downloaded.
  Pending entries survive restarts and stage downloads when their source is
  available, with download status, retry, and continue actions in track rows.
- Display settings to choose local-first or server-first ordering independently
  for Library, Playlists, and Liked Tracks.
- Account settings to sign out other app devices or all app devices, with
  confirmation. Both actions preserve admin-console sessions; signing out other
  devices also preserves the current app session.
- A mute/unmute control that restores the last audible app volume.

## Changed

- Original is the default stream quality at startup. The chooser labels the
  alternatives as High quality (160 kbps), Medium quality (96 kbps), and Low
  quality (48 kbps); the playback badge uses `OG` for Original.
- Windows playback uses XAudio2 by default, supports PCM32, and applies app
  volume to the playback source independently of the Windows mixer volume.
  Apple and Android audio adapters also support the higher-precision PCM path.
- File decoding and Original stream reads run in a session-owned isolate with
  bounded range caching, request deadlines, and cleanup when its owner exits.
  Original requests validate the trusted server identity and certificate before
  sending credentials, and reject redirects or invalid range responses.
- Account revision events refresh collections, shuffle presets, listening
  statistics, and account metadata, with snapshot recovery after reconnects,
  foreground transitions, or missed events. New server features are enabled only
  when the server advertises support.
- Listening statistics refresh from account notifications without triggering
  another upload. Active playback schedules contribution uploads approximately
  every 20 seconds while collection is enabled.
- Server catalogue changes refresh loaded library views and browse cursors
  without restarting current audio or deleting downloads.
- Open add-to-playlist dialogs reflect live collection changes and offer local
  and server destinations. Playlist membership updates and order changes handle
  concurrent edits and refresh stale state.
- Matching local recordings can resolve to the current server's tracks for
  server playlist actions, and a verified matching download can satisfy a local
  playlist addition without another download. Matching checks recording metadata
  and rejects ambiguous candidates.
- Local playlists share downloads for the same source track. Removing the last
  unfinished playlist request cleans up partial work while retaining completed
  media and downloads still requested elsewhere.
- Server custom shuffle filters are scoped to the trusted server and account;
  local filters remain device-specific. Repeat mode is saved on the device,
  with a one-time migration of the legacy server value.
- Desktop playback scales to the available width and height, retains side
  navigation in short tiled windows, and uses a minimum usable content size of
  600 by 360. Mobile landscape keeps the compact shell.
- Compact playback controls include Stop. Compact transport controls and mobile
  modal controls use larger touch targets, and settings switches support
  keyboard activation and accessibility semantics.
- Selecting the active main navigation tab again returns to the first page in
  that tab.
- A full Windows uninstall removes the app's settings, listening statistics,
  downloads, and logs under `%APPDATA%\Phonolite`, with a confirmation notice.
  Updates and reinstalls preserve that data through upgrade mode. External
  storage and unrelated files in the installation directory are preserved.

## Fixed

- Corrected iOS Now Playing album artwork when advancing through a shuffle deck.
  Upcoming shuffle artwork is preloaded for Flutter and native Now Playing,
  with bounded caches and protection against stale artwork results.
- Local shuffle continues with a new queue at the end of its current queue,
  preserves the selected playlist, artist, or album context, and avoids an
  immediate repeat when another track is available.
- Queue navigation retains the actual cursor when the same track appears more
  than once, rather than selecting its first occurrence.
- Switching stream quality retains the current playback position and pause
  intent. Failed file reads stop playback work before releasing decoder resources.
- Corrected seeking inside a large final 32-bit FLAC frame with a vendored
  Symphonia demuxer fix.
- Local and server track matching uses source identity to avoid confusing tracks
  with identical IDs from different servers. Remote track artwork is requested
  only from the matching server.
- Playback restoration skips removed entries, retains surviving shuffle order,
  handles deleted sources, and defers temporary failures without erasing saved
  history. Account changes isolate cached playback and pending operations.
- Rapid desktop and listening-statistics setting changes are serialized so
  accepted changes are persisted. Closing the desktop window waits for pending
  setting writes.
- Playlist dialogs reject stale account actions and prevent overlapping
  mutations; concurrent playlist edits produce a refresh instead of silently
  applying stale ordering.

## Compatibility

- Original supports mono and stereo MP3/FLAC sources. Android 12 or later is
  required for Original MP3 and audio requiring more than 24 bits of integer
  precision; older Android versions support up to 24 valid bits through float
  output. Unsupported formats or precision are rejected without an automatic
  fallback to an Opus quality.
- The operating-system mixer and audio hardware can still convert the output
  format. Original preserves the source through Phonolite's decoder and buffers.
- Account presets, session management, catalogue notifications, and account
  playback restoration depend on the server's advertised capabilities. See
  [account synchronization](https://github.com/PhonoliteOrg/phonolite-app/blob/v0.3.0/docs/account-sync.md)
  and [Original audio playback](https://github.com/PhonoliteOrg/phonolite-app/blob/v0.3.0/docs/original-audio-playback.md)
  for details.
